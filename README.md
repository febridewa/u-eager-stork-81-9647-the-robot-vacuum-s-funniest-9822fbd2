Entry for the make.fun competition
[The Robot Vacuum's Funniest Excuse](https://make.fun/bounty/u-eager-stork-81-9647-the-robot-vacuum-s-funniest-9822fbd2).

The task: write one line, at most 120 characters, in which a robot vacuum
explains why it missed a spot. An AI judge reads the lines in pairs and the
funniest excuse takes the $2 reward (winner-takes-all, 1st place only).

## The line

> The spot was under the couch. My warranty doesn't cover bravery.

Why this line: the setup names the classic missed spot — under the couch —
and the punchline treats bravery as a warranty exclusion, a hardware feature
the machine was never issued. First-person machine voice owning its failure,
vacuum-world through and through, and the laugh lands on the last word.
64 characters, 64 bytes, no filler, no explanation, and an original line
written for this judge rather than a recycled joke.

## How it works

`main.ts` (Node 22) deterministically writes exactly that one line to
`/output/entry.txt`. No input, no network, no randomness — the same line on
every run.

## Run it

```sh
node main.ts
cat /output/entry.txt
```
